# 🐦 STM32 Flappy Bird (SSD1306 OLED + Push Button)

Классическая аркадная игра **Flappy Bird**, написанная с нуля на языке **C** для микроконтроллера **STM32F103** (Blue Pill) и монохромного OLED-дисплея **SSD1306** (128x64, I2C) с управлением одной тактовой кнопкой.

Проект разработан без сторонних графических библиотек — от битовой адресации видеопамяти и I2C-драйвера до физики падения и детекции коллизий.

---

## 🎮 Демонстрация и особенности

* **Собственный видеодрайвер SSD1306:**
  * Видеопамять (фреймбуфер) размером ровно 1 КБ (1024 байта) в ОЗУ микроконтроллера.
  * Аппаратный I2C на частоте **400 кГц (Fast Mode)** для плавной анимации без мерцания.
  * Базовые графические примитивы: `draw_pixel`, `fill_rect`, `draw_rect`, `draw_bitmap`.
* **Встроенный шрифт 5x7:**
  * Полный набор символов ASCII (занимает всего 475 байт Flash-памяти).
  * Вывод текста и форматированного счёта очков.
* **Игровой цикл (Game Loop):**
  * Паттерн *Input $\to$ Update $\to$ Render* с фиксированным фреймрейтом **30 FPS** на базе системного таймера `HAL_GetTick()`.
  * Никаких блокирующих `HAL_Delay()` в основном цикле — мгновенный отклик на нажатие кнопки.
* **Физика и геймплей:**
  * Субпиксельная физика: ускорение свободного падения ($g$), импульс прыжка и расчёт траектории.
  * Генерация бесконечного потока препятствий со случайной высотой просвета.
  * Точная детекция столкновений методом **AABB** (Axis-Aligned Bounding Box).
* **Конечный автомат состояний (FSM):**
  * `STATE_MENU` — заставка с названием игры и ожиданием старта.
  * `STATE_PLAYING` — активный игровой процесс с подсчётом очков в реальном времени.
  * `STATE_GAME_OVER` — застывшая сцена с диалоговым окном и предложением сыграть снова.
* **Обработка кнопки:**
  * Использование внутреннего резистора подтяжки `GPIO_PULLUP`.
  * Детекция фронта нажатия (Edge Triggering) — исключает ложные срабатывания при зажатии.

## 🛠 Аппаратная часть (Hardware)

* **Микроконтроллер:** STM32F103C6T6 / STM32F103C8T6 (Blue Pill) — ядро ARM Cortex-M3 (72 МГц).
* **Дисплей:** 0.96" OLED SSD1306 (128x64, I2C, адрес `0x3C`).
* **Управление:** Любая тактовая кнопка (Normally Open).
* **Программатор:** ST-Link V2 (SWD).

### Схема подключения

| Модуль | Вывод модуля | Вывод STM32F103 | Примечание |
| :--- | :--- | :--- | :--- |
| **OLED SSD1306** | **GND** | **GND** | Общая земля |
| | **VCC** | **3.3V** | Питание логики |
| | **SCL** | **PB6** | I2C1 Clock (Open-Drain, 400 kHz) |
| | **SDA** | **PB7** | I2C1 Data (Open-Drain, 400 kHz) |
| **Кнопка** | Контакт 1 | **PA0** | Цифровой вход со встроенным PULL-UP |
| | Контакт 2 | **GND** | Замыкание на землю при клике |
| **ST-Link V2** | **SWCLK** | **PA14 (DCLK)** | Тактирование отладки SWD |
| | **SWDIO** | **PA13 (DIO)** | Данные отладки SWD |
| | **GND** | **GND** | Земля |
| | **3.3V** | **3.3V** | Только если плата не питается от USB! |

> [!NOTE]
> Перемычки режима загрузки платы Blue Pill должны стоять в рабочем положении: **BOOT0 = 0**, **BOOT1 = 0**.

## 🚀 Сборка и прошивка

Проект настроен для сборки в среде **PlatformIO** (VSCode):

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/stm32-oled-flappy-bird.git
   cd stm32-oled-flappy-bird
   ```
2. Откройте папку проекта в **VSCode** с установленным расширением **PlatformIO IDE**.
3. Подключите плату через **ST-Link V2**.
4. Нажмите кнопку **PlatformIO: Upload** (стрелочка в нижней строке состояния) или выполните команду в терминале:
   ```bash
   pio run -t upload
   ```
